# Runtime dependencies of the hosted dashboard (Render, Docker, Hugging Face Spaces).
#
# Deliberately much smaller than requirements.txt, which is the local *development* set
# (torch, pandas, matplotlib, gymnasium and pytest for training, benchmarking and tests).
# The live site imports only numpy + PyYAML from the project side and fastapi + uvicorn on
# the serving side; torch is intentionally absent - rl.nn_backend: auto falls back to the
# from-scratch NumPy dueling network (src/atsc/agents/net.py), which loads the same shipped
# checkpoint and picks the same greedy actions.
#
# EVERY package is pinned, transitive ones included, so a rebuild next month installs exactly
# what was tested (pip otherwise picks the newest version of anything left open - that is
# how an unpinned `websockets` can change under an unchanged uvicorn). websockets is held at
# 13.1, the last release before its legacy server API (the one uvicorn 0.30.1 uses) was
# deprecated. All 38 have binary wheels for CPython 3.12 on x86-64 Linux, so nothing is
# compiled during the Render build.
#
#   pip install -r requirements-deploy.txt
#   uvicorn asgi:app --host 0.0.0.0 --port $PORT --ws-max-size 65536
#
# To upgrade: edit the five direct pins, re-resolve the rest with
#   uv pip compile <direct pins> --python-version 3.12 --no-annotate
# and run `pytest` plus `python tools/e2e_browser.py --local` before pushing.
