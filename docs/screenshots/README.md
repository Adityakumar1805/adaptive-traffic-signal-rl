# Screenshots

Benchmark plots (`comparison_kpis.png`, `rl_improvement.png`, `emergency_clearance.png`) are
auto-generated by `python run.py eval` and copied here from `outputs/`.

The two `network_render_*.png` files show the live dashboard's network canvas: the RL-vs-fixed
pair and the emergency pre-emption corridor. Regenerate them by running `python run.py demo`
and screenshotting the network panels, or leave them as-is — they are reference stills, not
build artefacts.
